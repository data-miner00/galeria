# Objectives

A self-hosted authenticationless image board used for

1. Organizing own images
2. Organizing interested internet photos
3. Create board / list
4. Add description / notes
5. Maybe need authentication, for collaborator
6. Image manipulation capabilities.
7. Masonry layout
8. Dark-light mode
9. Internationalization
10. Enable categorization / tagging
11. Filter
12. Support GIF?

Should be simple and quick. Aim to get MVP by 22 March 2026.

## Image Store

1. File storage repository.
2. Azure Storage Account (Emulator)
3. Azure Cosmos DB
4. SQ Lite
5. Mongo DB
